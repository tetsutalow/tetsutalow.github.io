1文法の入力

1行に1規則。→ は -> でも可、選択は |、空列は ε。左辺に現れる記号が非終端記号、最初の規則の左辺が開始記号。右辺の記号を空白で区切ると if else := のような単語が1つの記号になります。

2閉包（Closure）と LR(0) 状態遷移図（正準オートマトン）

初期状態の閉包から始め、Goto(I, α) を新しい閉包が現れなくなるまで繰り返します。
完全項を含む閉包青字 不都合な状態丸はドラッグで動かせます／クリックで閉包を表示
