# LL(1) 文法の判定と再帰的下向き構文解析の可視化

文法を入力すると、講義「言語処理系 第5回 構文解析・下向き構文解析法」の手順に沿って

1. First 集合（教科書 p.52）
2. Follow 集合（教科書 p.53）
3. Director 集合
4. LL(1) 文法であるかの判定（Director 集合の重なりと左再帰性）
5. LL(1) 文法なら、文字列を入力して再帰的下向き構文解析の様子（入力の先読み位置・疑似コードの実行行・呼び出しの入れ子・最左導出列・構文木）

を手順ごとに表示する Web ページです。JavaScript のみで動作し、外部ライブラリは使いません。

## 使い方

`index.html` をブラウザで開くだけです（サーバ不要）。

- 文法は 1 行に 1 つの左辺を書き、選択肢は `|` で区切ります（`→` または `->`）。
- 左辺に現れる記号が非終端記号です。右辺の残りは 1 文字ずつ終端記号になります。`E'` のようにプライムを付けた名前は 1 つの記号です。複数文字の終端記号は `"if"` のように書けます。
- `ε` は空列、`$` は入力の終わりを表す記号です。
- 「左再帰を除去」「括り出し」ボタンで、教科書 p.49 / p.51 の書き換えを自動で行い、再解析します。
- 「例文を作る」ボタンは文法から受理される文字列を乱択で作ります。

## ファイル構成

- `index.html` — ページ本体
- `css/style.css` — 見た目
- `js/grammar.js` — 文法の読み込み、First / Follow / Director、LL(1) 判定、左再帰除去・括り出し、構文解析のトレース（表示と独立。Node.js からも `require` できる）
- `js/draw.js` — 構文木の SVG 描画
- `js/app.js` — 画面の組み立てとステップ操作
