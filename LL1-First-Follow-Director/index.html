文法 → First / Follow / Director 集合 → LL(1) 判定 → 構文解析

文法を入力すると、First集合・Follow集合・Director集合を順に求め、LL(1)文法かどうかを判定します。LL(1)文法なら文字列を入力して再帰的下向き構文解析の様子と構文木を表示します。

文法の入力

例:
書き方
  • 1行に1つの左辺を書き、右辺の選択肢は | で区切ります（→ の代わりに -> も可）。行頭が | の行は前の行の続きです。
  • 左辺に現れる記号が非終端記号です。右辺では非終端記号名を最長一致で切り出し、残りは1文字ずつ終端記号になります。空白は無視されます。
  • E' のように ' を付けた名前は1つの記号です。〈式〉 や <expr> も1つの記号です。
  • 複数文字の終端記号は "if" のように " で囲みます（非終端記号名と重ならなければ囲まなくても構いません）。
  • ε は空列です。$ は入力の終わりを表す記号なので文法中では使えません。最初の左辺が開始記号になります（変更可）。

1. First 集合（教科書 p.52）

First(α)：α の先頭になりうる終端記号の集合。

  • First(ε) = {ε}，First(aα) = {a}
  • First(Y) に ε が含まれていなければ First(Yα) = First(Y)，含まれていれば First(Yα) = (First(Y) − {ε}) ∪ First(α)
  • X → α なら First(X) に First(α) を加え、どの非終端記号にもそれ以上追加できなくなるまで繰り返す

2. Follow 集合（教科書 p.53）

Follow(A)：A の直後に現れうる終端記号の集合。

  • 開始記号 S について Follow(S) に $ を加える（$ は読み込み終わりを表す特殊記号）
  • A → αBβ のとき First(β) を Follow(B) に加える（ε は除く）
  • First(β) に ε が含まれるとき（または β = ε のとき）は Follow(A) を Follow(B) に加える
  • これを加えるものがなくなるまで繰り返す

3. Director 集合

Director(A, α)：First(α)，ただし α が ε になりうる（α ⇒* ε）場合には Follow(A) も加えたもの。生成規則 A → α を適用すべき（先読みした際の）終端記号の集合。

4. LL(1) 文法であるかの判定

左再帰性がなく、かつ A → α | β のとき Director(A, α) ∩ Director(A, β) = Φ（空集合）をあらゆる生成規則について満たす文法が LL(1) 文法。生成規則に | が出てくる（または左辺に重複して出てくる）非終端記号について Director 集合を調べればよい。

5. 再帰的下向き構文解析

各非終端記号を関数にし、集合和 | のある所では1字句だけ先読みして Director 集合に含まれる生成規則を選ぶ（LL(1) なので必ず1つに決まり、バックトラックは起きない）。
