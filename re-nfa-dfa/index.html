正規表現 → NFA → DFA → 状態数最小化DFA

正規表現を入力すると、NFA への変換・部分集合構成法による DFA 化・Moore's Algorithm による状態数最小化を順を追って表示します。

例:

使える記法: 連接 ab、選択 a|b、閉包 a*、括弧 ( )、空列 ε。 + や ? は普通の記号として扱います。記号として *|()\ を使うときは \* のようにバックスラッシュを前に付けます。

1正規表現 → NFA

  • 記号 x は、新しい状態への x 遷移 1 本になる。
  • 連接 AB は A の終わりの状態を B の始まりの状態にする。
  • 選択 A|B は始まりと終わりの状態を共有して 2 つの枝を作る。
  • 閉包 A* は ε 遷移で「入る」「戻る」「読み飛ばす」「抜ける」の 4 本を足す。

    2NFA → DFA（部分集合構成法）

    • 初期状態から ε で辿れる全ての状態をひとつにまとめ、これを初期状態にする。
    • ある状態から、同じ入力に対する遷移先はまとめてひとつの状態にする（ε があればその遷移先も 1 つにまとめる）。
    • まとめた状態の中に 1 つでも受理状態があれば、まとめた後も受理状態にする。
    • 「まとめた」状態で元の状態の組合せが違えば別の状態と見なす。これをひたすら繰り返す。

    4DFA の状態数最小化・ムーアのアルゴリズム（Moore's Algorithm）

    • まず全状態を受理状態とその他のグループに分ける。
    • 入力に対する遷移先を表にし、遷移先がどのグループに属するかを見る。
    • 同一グループ内で、遷移先グループのパターンが異なる状態があれば「矛盾」なので分割する。
    • これを分割できなくなるまで繰り返す。
