# 正規表現 → NFA → DFA → 状態数最小化DFA 可視化ツール

正規表現を入力すると、以下を順を追ってグラフィカルに表示する Web ページです。
JavaScript のみで記述しており、外部ライブラリやサーバは不要です（`index.html` をブラウザで開くだけ）。

1. **正規表現 → NFA** … 講義の図3.6 と同じ構成法。遷移が 1 本ずつ追加される様子をステップ表示
2. **NFA → DFA（部分集合構成法）** … 「状態 X から各記号で辿れる範囲をまとめる」をスライドと同じ順で 1 状態ずつ展開。NFA 側の該当状態を色で強調
3. **ラベルの振り直し** … DFA の各状態に あ・い・う… を付け直し、状態遷移表を表示
4. **Moore's Algorithm による状態数最小化** … 受理/非受理で初期分割 → Group / 状態 / 遷移先∈グループ の表 → 矛盾する行を分割 → 分割できなくなるまで繰り返し（各ラウンドをステップ表示）
5. **最小 DFA** … α, β, γ… でラベル付けした最小 DFA と遷移表、文字列の受理テスト

## ファイル構成

```
index.html        画面の骨組み
css/style.css     スタイル
js/automata.js    構文解析・NFA 構成・部分集合構成法・Moore's Algorithm（表示に依存しない純粋な計算）
js/draw.js        NFA / DFA を SVG で描画（レイアウト含む）
js/app.js         画面の組み立て・ステッパー・表の生成
```

## 使える記法

| 記法 | 意味 |
|---|---|
| `ab` | 連接 |
| `a\|b` | 選択 |
| `a*` | 閉包（0回以上） |
| `( )` | グループ化 |
| `ε` | 空列 |
| `\*` `\|` `\(` `\)` `\\` | 演算子を記号として使う |

`+` と `?` は演算子ではなく普通の記号として扱います。

URL の `#` 以降に正規表現を付けると、その式を読み込んだ状態で開きます（例: `index.html#(a|b)*ab`）。

## 実装メモ

- NFA の構成は `build(node, start, end)` の再帰で行い、状態番号が左から右へ並ぶようにしている（講義の図と同じ番号になる）。
  選択 `A|B` は始点と終点を共有、閉包 `A*` は「入る・戻る・読み飛ばす・抜ける」の 4 本の ε 遷移を追加。
- 部分集合構成法では遷移がない入力は空欄（死状態は作らない）。Moore's Algorithm でも「遷移なし」を 1 つのパターンとして扱う。
- Moore's Algorithm の分割では各グループ内の出現順を保って分ける。
